# رصد جهانی — اخبار مهم اقتصاد، کریپتو و تکنولوژی

این ربات به‌صورت خودکار (با GitHub Actions) اخبار خیلی مهم دنیا در سه حوزه‌ی **اقتصاد کلان و بازارهای مالی**، **کریپتو** و **تکنولوژی** را جمع‌آوری می‌کند، با هوش مصنوعی خلاصه و فیلتر می‌کند، و فقط مهم‌ترین‌ها را (نه هر خبری) به‌صورت خلاصه‌ی چند خطی به تلگرام می‌فرستد. اخبار سیاسی صرف نادیده گرفته می‌شود. یک صفحه‌ی html هم آرشیو کامل را نمایش می‌دهد.

## چطور کار می‌کند

- هر ساعت یک‌بار GitHub Action اجرا می‌شود، اخبار را جست‌وجو و تحلیل می‌کند و در `news.json` ذخیره می‌کند.
- ارسال به تلگرام فقط داخل ۴ بازه‌ی زمانی مشخص (حدود ۹، ۱۳، ۱۷ و ۲۱ به وقت تهران) انجام می‌شود — نه هر بار — تا حجم پیام‌ها کم بماند.
- در هر ارسال فقط خبرهایی که امتیاز اهمیت (urgency) آن‌ها ۷ از ۱۰ یا بیشتر است فرستاده می‌شوند (حداکثر ۶ خبر در هر پیام).
- `index.html` همیشه با آخرین `news.json` آپدیت می‌شود و می‌توانی آن را روی GitHub Pages میزبانی کنی.

## راه‌اندازی

1. یک ریپوی جدید در گیت‌هاب بساز و همه‌ی این فایل‌ها را در آن قرار بده (یا این ریپو را push کن).
2. به `Settings → Secrets and variables → Actions` برو و این‌ها را اضافه کن:
   - `TG_BOT_TOKEN` — توکن ربات تلگرامی که با BotFather ساختی
   - `TG_CHANNEL_ID` — آیدی کانال/گروه مقصد (مثلاً `@my_channel` یا عدد chat id)
   - `POLLINATIONS_API_KEY` — کلید رایگان از [pollinations.ai](https://pollinations.ai) برای تحلیل هوش مصنوعی
3. (اختیاری) یک Variable با نام `SITE_URL` اضافه کن که آدرس صفحه‌ی GitHub Pages‌ات باشد، تا لینک آرشیو در پیام‌های تلگرام باشد.
4. از تب `Settings → Pages` گیت‌هاب را فعال کن تا `index.html` روی وب در دسترس باشد.
5. از تب `Actions` می‌توانی ورک‌فلو را دستی هم اجرا کنی (`workflow_dispatch`) — حتی می‌توانی یک لینک خبر خاص بدهی تا فقط همان تحلیل و ارسال شود.

## تنظیمات قابل تغییر (داخل `main.py`، دیکشنری `CONFIG`)

- `SEARCH_QUERIES` — کوئری‌های جست‌وجو؛ می‌توانی موضوعات بیشتری اضافه کنی.
- `MIN_TELEGRAM_URGENCY` — هرچه بالاتر، فقط خبرهای مهم‌تر ارسال می‌شوند (پیش‌فرض: ۷).
- `MAX_DIGEST_ITEMS` — حداکثر تعداد خبر در هر پیام تلگرام (پیش‌فرض: ۶).
- `DIGEST_SLOTS` — بازه‌های ساعتی ارسال به وقت تهران.

## نکته درباره‌ی هوش مصنوعی

از همان روش پروژه‌ی اصلی (Pollinations API، رایگان و بدون نیاز به کلید OpenAI) استفاده شده. اگر بعداً خواستی به Claude/OpenAI/... سوییچ کنی، فقط باید تابع `analyze_with_ai` در `main.py` را عوض کنی.
